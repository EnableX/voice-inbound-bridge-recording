Inbound Bridge Recording SAMPLE APP

Receive an inbound call, bridge it to another number, and record the conversation automatically.

1
Install dependencies
npm install
2
Configure credentials
cp env-example .env

Edit .env and fill in:

  • ENABLEX_APP_ID and ENABLEX_APP_KEY — from the EnableX portal
  • FROM — your EnableX virtual number (the caller ID used when bridging)
  • BRIDGETO — the destination number inbound calls will be bridged to
  • LISTEN_SSL=false for local testing
3
Create an ngrok tunnel
ngrok http 3000

Copy the https://…ngrok.io URL and set it as PUBLIC_WEBHOOK_URL in .env.

4
Configure portal webhook

In the EnableX portal, set your virtual number's webhook URL to the ngrok URL + /event.

5
Start the server
npm start

Open http://localhost:3000. Inbound calls will be handled automatically.
